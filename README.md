# Квест-майстер: 2 агенти + власний MCP-сервер

```
Гравець -> Оповідач (get_world_state) -> Арбітр (get_world_state, roll_dice, update_state) -> world.json
                         \_______ MCP-клієнт (mcp_client.py) -> MCP-сервер quest (server.py, stdio) ______/
```

Писати у світ може лише Арбітр. Це примусово перевіряється в `QuestClient.call`
(інакше повертається помилка `forbidden`), а не лише описано в промпті.

## Запуск
```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишіть OPENROUTER_API_KEY

python main.py --random --seed 5       # випадковий старт + випадкові події
python main.py --reset                 # фіксований старт, події теж увімкнені
python main.py --reset --no-events     # без випадкових подій
python main.py --reset --mode single   # baseline: один агент
python eval.py                         # 5 тестів x (multi + single), таблиця і results.json
```

## Файли
| Файл | Що |
|---|---|
| `server.py` | MCP-сервер, 3 інструменти, помилки як дані |
| `mcp_client.py` | MCP-клієнт, перевірка прав, трейсер (`trace.jsonl`) |
| `agents.py` | промпти, цикл tool-calling через OpenRouter, `play_turn_multi/single` |
| `eval.py` | 5 тестів, автоперевірка за станом світу, токени й виклики |
| `main.py` | інтерактивна гра для відео-демо |
| `worldgen.py` | випадковий старт: мапа, hp, золото, інвентар, квест (за seed) |
| `events.py` | Директор подій: випадкові події у випадкові моменти (за seed) |
| `test_offline.py` | перевірки генератора й директора без LLM |

## Трейсинг
`trace.jsonl`: кожен виклик інструмента (агент, аргументи, результат, мс) і кожен виклик LLM (токени).
Для дерева викликів у Langfuse додайте `from langfuse.openai import AsyncOpenAI` замість `openai`
(інструментує LLM-виклики) і відправляйте події `Tracer.emit` як spans.

## Нотатки
- Seed кубика фіксований (`SEED = 7` в eval.py), сервер запускається заново на кожен тест.
- Сервер не друкує в stdout, бо його використовує stdio-транспорт MCP.
- `mcp` закріплено `<2`: у 2.x `FastMCP` перейменовано.

## Варіативність
- **Старт** (`worldgen.py`): 1-3 додаткові локації (ринок, ліс, печера, міст) з гарантованою зв'язністю мапи,
  випадкові hp 8..20, золото 10..60, зброя + 1-2 предмети, квест-гачок для Оповідача.
- **Події** (`events.py`): 7 типів (засідка, пастка, гаманець, цілитель, знахідка, злива, кишеньковий злодій),
  частина залежить від локації. Шанс події стартує з 15% і росте на 15% за кожен тихий хід (pity timer),
  після події скидається. Моменти випадкові, але довгих пауз немає.
- **Хто що робить:** Директор кидає подію й лише читає стан. Оповідач описує її, Арбітр застосовує ефект
  через `update_state`. Право писати все ще в одного агента. Single-agent baseline отримує ті самі події.
- **Eval лишається детермінованим:** `eval.py` бере шаблон і не вмикає події, щоб 5 тестів були порівнювані.
  Те саме `--seed` дає той самий світ, ті самі події й ті самі кидки кубика.
